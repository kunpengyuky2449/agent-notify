# Changelog

## 0.1.0 — 2026-10-05

- First standalone open-source Windows tray receiver and optional PowerShell sender.
- Native Windows banners, Notification Center, local inbox, one-instance activation and optional per-user startup.
- Pushover device login, encrypted sessions/keys, reconnect limits, durable queue processing and emergency acknowledgement.
- Guarded release/source installation, upgrades, uninstall that preserves user data, Windows ZIP/checksum packaging and offline CI checks.
- English/Chinese README, account/key tutorial, official pricing/registration links, gaming and cross-PC guides.
- Preserves working prototype credentials through legacy-location detection; fresh installs have independent Agent Notify storage.

Original-device live checks confirmed Android receipt, desktop/game banners and sound. Other machines, games and future API changes require fresh checks.
